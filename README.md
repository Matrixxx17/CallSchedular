# 📞 Call Scheduler

A simple and smart app that lets you **schedule phone calls** and get **reminders via notifications** — just tap the notification when it's time, and the call is made instantly.

## 🚀 Features

- 📅 **Schedule Calls**  
  Select a contact and set a desired time to schedule the call.
- 🔔 **Smart Notifications**  
  Get a timely notification reminding you to call — no need to open the app!
- 📲 **One-Tap Calling**  
  Tap the notification when it appears to immediately initiate the call.

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Matrixxx17/CallScheduler.git
   cd CallScheduler
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Install required Expo packages:
   ```bash
   npx expo install expo-notifications expo-system-ui
   ```

4. Run the app:
   ```bash
   npx expo start
   ```
